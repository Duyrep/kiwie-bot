# Hướng dẫn chạy dự án

---

## Yêu cầu chuẩn bị
- Máy đã cài sẵn **Node.js (phiên bản v22 trở lên)**.

---

## Các bước thực hiện

### Bước 1: Cài đặt pnpm (Nếu chưa có)
Nếu chưa cài `pnpm`, mở Terminal / Command Prompt và chạy lệnh:
```bash
npm install -g pnpm
```

### Bước 2: Cài đặt

Mở thư mục gốc của dự án và chạy:

```bash
pnpm install
```

### Bước 3: Chạy

Để bắt đầu chạy dự án:

```bash
pnpm startt
```
