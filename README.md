# Hướng dẫn thiết lập dự án

---

## Yêu cầu hệ thống
- Cần cài đặt **Node.js (phiên bản v22 trở lên)**.

---

## Các bước thực hiện

### Bước 1: Cài đặt pnpm (Nếu chưa cài đặt)
Nếu bạn chưa cài đặt `pnpm`, hãy mở Terminal hoặc Command Prompt và chạy lệnh sau:
```bash
npm install -g pnpm

```

### Bước 2: Cài đặt


```bash
pnpm install

```

### Bước 3: Triển khai


```bash
pnpm discord-deploy

```

### Bước 4: Khởi chạy


```bash
pnpm start

```
